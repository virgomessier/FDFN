## Предварительные условия

- VPS с Ubuntu 24.04.
- Публичный IPv4.
- SSH-доступ по ключу.
- Созданный Telegram-бот.
- Приватный репозиторий из template.

## Последовательность

1. Пользователь добавляет конфигурацию и GitHub Secrets.
2. Workflow проверяет конфигурацию и наличие обязательных секретов.
3. Workflow проверяет SSH-соединение и fingerprint сервера.
4. Ansible приводит VPS к описанному состоянию.
5. Выполняется проверка systemd-сервисов и Xray-конфигурации.
6. Результат публикуется в GitHub Actions Summary.

## Поведение при ошибке

Workflow останавливается на первом критическом сбое.
Повторный запуск должен безопасно продолжить deployment.
