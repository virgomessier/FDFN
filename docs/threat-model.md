## Угрозы и меры защиты

### Подбор SSH-учётных данных

- Вход только по ключу.
- PasswordAuthentication отключён.
- Root login отключён.
- Открыт только необходимый SSH-порт.

### Несанкционированное управление ботом

- Разрешены только private chat.
- Администратор проверяется по неизменяемому Telegram user ID.
- Username не используется для авторизации.
- Bot token не хранится в репозитории.

### Доступ к Xray API

- API слушает только localhost или Unix socket.
- Порт API не открывается в firewall.
- vpn-manager работает без root-прав.

### Сканирование публичных портов

- Разрешены только используемые порты.
- Неуспешные подключения не предоставляют доступ к прокси.
- Логи ограничены по размеру и сроку хранения.

### Перегрузка сервера

FDFN не гарантирует защиту от распределённого DDoS.
Проект может только ограничивать последствия локальными лимитами
и средствами VPS-провайдера.
