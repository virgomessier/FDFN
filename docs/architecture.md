## Компоненты

### vpn-manager

Содержит бизнес-логику управления пользователями и credentials.
Является единственным компонентом, изменяющим желаемое состояние.

### Telegram-бот

Проверяет Telegram ID администратора и передаёт команды
vpn-manager. Не взаимодействует с Xray и SQLite напрямую.

### SQLite

Хранит желаемое состояние пользователей и credentials.

### Xray

Обслуживает клиентские подключения. Получает изменения
от vpn-manager через локальный адаптер.
