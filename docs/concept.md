# Концепция FDFN

Быстро развертываемый vpn сервис, с минимальными затратами и накладными серверными расходами. Для быстрого доступа к сети в заблокированных регионах с строгими ограничениями провайдеров или государственных органов.

## Проблема

Самостоятельное развёртывание Xray требует знания Linux,
конфигурации Xray, systemd, firewall и управления пользователями.

## Решение

FDFN автоматизирует развёртывание и предоставляет минимальный
интерфейс управления через Telegram-бота.

## Целевая аудитория

Пользователь с базовым пониманием VPS, SSH и GitHub,
которому нужен личный сервис для группы из 5–10 человек

## Основные ограничения

- Один VPS.
- Один администратор.
- Без веб-панели и платежей.
- Минимальные требования к серверным ресурсам.
