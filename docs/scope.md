## MVP

- Один VPS с Ubuntu 24.04.
- Один профиль: VLESS + REALITY + RAW + Vision.
- Xray, vpn-manager, Telegram-бот и SQLite на хосте через systemd.
- Развёртывание Ansible из GitHub Actions.
- Один Telegram-администратор.
- Создание, экспорт и отзыв credential.

## Не входит в MVP

- Multi-node.
- XHTTP + TLS/IP-сертификаты.
- Nginx перед REALITY.
- AmneziaWG/WireGuard.
- Веб-панель.
- Автоматическая миграция IP без переимпорта конфигов.
- Backup/restore SQLite.
